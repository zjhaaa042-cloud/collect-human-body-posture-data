# 体态数据采集系统 v1.0.5

## 更新内容

- 修复右侧恢复提示挤压采集界面的问题，长错误可滚动查看。
- 修复角度写入异常后的进度和锁定状态同步，并补齐文件日志。
- 避免已落盘数据因重复读取失败而被误报为采集失败。
- 修复采集中切换受试者导致进度错配、打开任务失败后目录残留的问题。
- 拒绝普通请求重复采集已完成角度。
- 新增自动读取最新受试者：启动或选择输出目录后，按编号最大恢复已有任务及进度；支持手动读取。空目录不自动新建任务，损坏的最新任务会明确报错。

## 安装

下载 `BodyPostureCollector-Setup-1.0.5.exe`，退出旧版采集程序后运行安装。安装后选择原来的数据输出目录，即可读取已有任务。

同时提供 SHA-256 校验文件。本安装包为 Windows x64 版本，包含 Python 后端、Electron 前端、相机依赖及模型资源。
